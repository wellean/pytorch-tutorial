GitHub Copilot:

在 Linux 服务器上查询 GPU（显卡）信息，最常用有以下几种方法。您可以直接在终端中运行这些命令：

### 1. 使用 `nvidia-smi` (最常用)
如果服务器安装了 NVIDIA 显卡及驱动，输入以下命令：
```bash
nvidia-smi
```
**它会显示什么：**
- **GPU 型号**（例如 RTX 3090, Tesla V100 等）
- **Driver Version**（显卡驱动版本）
- **CUDA Version**（最高支持的 CUDA 版本）
- **显存使用情况**（Memory-Usage）

### 2. 使用 `lspci` 命令查看硬件层面信息
如果您想查看服务器主板上插了哪些显卡设备，可以运行：
```bash
lspci | grep -i nvidia
```
或者查看所有图形显卡：
```bash
lspci | grep -i vga
```

### 3. 查看 CUDA 运行平台版本 
如果您想查看当前系统安装并配置的 CUDA Toolkit 的具体版本，可以使用：
```bash
nvcc --version
```

**建议：**通常您只需要运行 `nvidia-smi` 就能得到绝大多数关于 PyTorch 深度学习所需的环境信息。您可以根据 `nvidia-smi` 右上角的 `CUDA Version` 来决定上一步中应该安装哪个版本的 GPU PyTorch。
