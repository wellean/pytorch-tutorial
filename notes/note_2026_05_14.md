Optimized tool selection`net.train()` 的作用是将神经网络模型设置为**训练模式 (Training Mode)**。

### 有什么意义？
在 PyTorch 中，某些特定的层（如 **Dropout** 和 **BatchNorm**）在训练阶段和评估/测试阶段的内部运行逻辑是完全不同的：
1. **Dropout 层**：在训练模式下，它会自动随机“丢弃”（失活）一部分神经元来防止模型过拟合；但在测试模式下，我们需要所有神经元都参与工作，它就不会再丢弃节点。
2. **BatchNorm 层（批归一化）**：在训练模式下，它会实时计算当前 batch 的均值和方差，并不断更新整个数据集的全局统计量；而在测试模式下，它会停止更新，直接使用训练阶段累加下来的这套全局统计量。

### 必要吗？
**它是非常有必要的，也是编写 PyTorch 代码的标准化好习惯。** 
即使你当前自定义的 `Net()` 模型中没有用到 Dropout 或 BatchNorm 层，调用 `net.train()` 也不会产生任何负面影响。如果后面哪天修改模型加上了这些层，忘记写 `net.train()` 或测试时的 `net.eval()` 会导致极其隐蔽的 Bug。

### 💡 优化建议：位置调整
在你的代码中，`net.train()` 放在了获取数据的小循环（`for data in train_dataloader:`）里面。这意味着每一个 Batch 数据过来，它都会重新设置一次。

虽然这样写程序本身**不会报错**，但显得有点多余。更合理的做法是把它放在 `for i in range(epoch):` 的主体中，每次开启新一轮完整训练（或者说进入训练步骤）前调用一次即可：

```python
for i in range(epoch):
    print("第 {} 轮训练开始".format(i+1))
    
    # 将模型放入训练模式 (只需每轮训练前设置一次即可)
    net.train()     
    
    # 训练步骤开始
    for data in train_dataloader:
        images, labels = data
        outputs = net(images)
        # ... 后续代码
```

*注意：将来如果你在这个代码下面加上测试步骤（Test Step），在测试代码前也请务必加上与其对应的 `net.eval()` 来开启评估模式。*
