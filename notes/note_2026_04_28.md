GitHub Copilot:
你这个判断很可能是对的，最常见原因不是 Compose，而是 TensorBoard 日志冲突导致你看到的 step1 不是这次写进去的那张。

你现在代码里有两个高风险点：

1. 同一个 tag 重复写
test_resize 在 step 0/1/2 都被复用。

2. 同一个 log_dir 长期复用
你一直写到 logs，目录里已经有很多历史 event 文件。  
TensorBoard 会把同一路径下同 tag 同 step 的历史数据混在一起显示，step1 可能被旧记录“顶掉”成正方形。

建议你这样改，基本能一次定位：

```python
from datetime import datetime
from PIL import Image
from torch.utils.tensorboard import SummaryWriter
from torchvision import transforms

img_path = "E:/.../0013035.jpg"
img = Image.open(img_path)

run_dir = f"logs/p13_resize_debug_{datetime.now().strftime('%Y%m%d_%H%M%S')}"
writer = SummaryWriter(log_dir=run_dir)

trans_totensor = transforms.ToTensor()
trans_resize2 = transforms.Resize((2048, 4096))
trans_compose = transforms.Compose([trans_resize2, trans_totensor])

img_compose = trans_compose(img)

print("PIL original size (W,H):", img.size)
print("After resize2 PIL size (W,H):", trans_resize2(img).size)      # 预期 (4096, 2048)
print("Tensor shape (C,H,W):", img_compose.shape)                    # 预期 [3, 2048, 4096]

writer.add_image("resize_512_square", trans_totensor(transforms.Resize((512, 512))(img)), 0, dataformats="CHW")
writer.add_image("resize_2048x4096_rect", img_compose, 1, dataformats="CHW")
writer.add_image("randomcrop_512_square", transforms.Compose([transforms.RandomCrop(512), trans_totensor])(img), 2, dataformats="CHW")

writer.close()
print("log_dir =", run_dir)
```

如果你按这个跑，step1 还是方图，那就几乎可以确定是 TensorBoard 展示缩略图看起来方，但原图不是方。  
以控制台打印为准：  
- PIL 尺寸应是 (4096, 2048)  
- Tensor 形状应是 [3, 2048, 4096]

如果你愿意，我可以直接帮你把 P13.ipynb 这一格改成“防混淆版本”（唯一 log_dir + 唯一 tag + shape 打印）。

GitHub Copilot:
最可能的原因不是 `Compose`，而是 **TensorBoard 把不同运行的同名标签混在一起**，你看到的 `step1` 不是这次的那张。

你现在这行：

- `writer = SummaryWriter(log_dir="logs")`
- `writer.add_image("test_resize", ..., 0/1/2)`

会导致历史多次运行都写进同一个 `logs`，而且标签都叫 `test_resize`。  
这样 `step1` 很容易被旧记录覆盖成“看起来是正方形”。

另外再确认一点：

- `Resize(256)` 是“短边到 256，长宽比保持不变”
- 你的 `img_compose.shape = [3, 256, 384]` 已经证明它是长方形，不是正方形

可以这样彻底排查：

1. 每次运行用新的日志目录  
`SummaryWriter(log_dir=f"logs/p13_{time}")`
2. 每种图用不同 tag  
`test_resize_step0_square`、`test_resize_step1_rect`、`test_resize_step2_crop`
3. 显式写 `dataformats="CHW"`  
`writer.add_image(..., dataformats="CHW")`
4. 先删旧日志或切到新 run 再看

结论：你的 `step1` 在代码层面已经是长方形张量，显示成正方形基本是日志/展示层的问题，不是 `Compose` 变错了。
