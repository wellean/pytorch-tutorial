User: 解释一下dataset

GitHub Copilot: 这里的 Dataset 指的是 PyTorch 里的“数据集抽象基类”，核心作用是：定义“如何按索引取一个样本”。

你截图这段可以这样理解：

1. Dataset 是抽象基类  
它本身不提供真实数据，只规定接口，供你继承。

2. 必须实现 __getitem__(index)  
这是唯一强制的方法。  
DataLoader 在取数据时，最终会调用它。  
默认实现直接抛 NotImplementedError，就是在提醒你“子类必须自己写”。

3. 通常建议实现 __len__()  
不是强制，但强烈建议。  
很多采样器和 DataLoader 需要知道数据集长度，比如随机采样、进度估计、drop_last 等。

4. 可选实现 __getitems__(indices)  
这是批量索引接口（一次给你一组索引），有些场景可加速批量取样。  
不写也没问题，DataLoader 会逐个调用 __getitem__。

5. 这是“Map-style Dataset”  
也就是“索引 -> 样本”的风格（像数组/字典）。  
如果你的数据是流式迭代（不能随机索引），应使用 IterableDataset（同文件里也有）。

6. 对应注释里那句 non-integral keys  
DataLoader 默认采样器给的是整数索引。  
如果你的 key 不是整数（比如字符串 id），就要自定义 sampler。

一个最小自定义例子：

```python
from torch.utils.data import Dataset

class MyDataset(Dataset):
    def __init__(self, xs, ys):
        self.xs = xs
        self.ys = ys

    def __getitem__(self, index):
        return self.xs[index], self.ys[index]

    def __len__(self):
        return len(self.xs)
```

然后就能配合 DataLoader 使用：

```python
from torch.utils.data import DataLoader

loader = DataLoader(MyDataset(xs, ys), batch_size=32, shuffle=True)
```
